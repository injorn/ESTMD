# นำเข้ารายการงานจาก Excel แล้วประเมิน MD

เมนู **โครงการ → นำเข้าจาก Excel** (`/projects/import`) สำหรับ admin และ estimator ใช้กับไฟล์ `.xlsx` รูปแบบเดียวกับตัวอย่างใน `pttdigitalMD` แม้ยังไม่ได้กรอก MD ไม่ต้องเปลี่ยนทุกไฟล์เป็น Template เดียว

## วิธีใช้

1. เลือกไฟล์ Excel แล้วกด **อัปโหลดและเลือกตาราง**
2. เลือกชีตที่มีรายละเอียดงาน กำหนดช่วงแถวและคอลัมน์ **รายละเอียดงาน** ส่วน Phase, จำนวน, สิ่งส่งมอบ และกำหนดส่งเลือกเพิ่มได้ ตรวจตัวอย่างในตาราง หากไม่เลือกจำนวน ระบบใช้ 1; หากเลือกคอลัมน์จำนวนแต่เซลล์ว่าง/ผิด ต้องแก้ในหน้าตรวจรายการหรือไม่เลือกแถวนั้น
3. กด **ตรวจรายการก่อนนำเข้า** แล้วตรวจว่าตัดแถวชื่อโครงการ หัวตาราง ยอดรวม อัตรา ราคา และข้อมูลอื่นที่ไม่ใช่งานออกแล้ว ระบบช่วยไม่เลือกหัวข้อ/ยอดรวมที่จำแนกได้ในเบื้องต้น แต่ผู้ประเมินเป็นผู้ตรวจยืนยัน
4. ตั้งชื่อ/รหัสโครงการ และเลือก Technology Stack กำหนดรูปแบบงานแต่ละ Phase: พัฒนาเองใช้ Matrix; SAP/Vendor/Migration ลง MD ตามบทบาท
5. ถ้ารู้ Activity ให้เลือก Matrix, L/M/H และจำนวนไว้ ระบบจะคำนวณ MD ใหม่เมื่อนำเข้า กิจกรรม Matrix ที่นับต่อโครงการใช้จำนวน 1 ถ้ายังไม่รู้ให้เว้น Activity ไว้ รายการยังอยู่ครบและแสดง **รอประเมิน**
6. กด **สร้างโครงการจาก … รายการ** ระบบสร้างร่างและเปิดขั้นรายการงาน ในแต่ละรายการเปิด **แก้รายการ / แรงงาน / แหล่งอ้างอิง** เพื่อจับคู่ Activity เลือกระดับ/จำนวน แก้รายละเอียด/สิ่งส่งมอบ/กำหนดส่ง หรือกรอก MD รวมตามบทบาท
7. เลือกบทบาทที่จะรวมและอัตราในขั้น **ทีม & อัตรา** (บทบาทเพิ่ม เช่น PM/SAP อาจยังไม่ได้เลือกในค่าเริ่มต้น) แล้วเปิดสรุปและกด **Export Excel**

## ความหมายของค่าที่ได้

- ใช้เฉพาะรายการงาน ไม่ดึง MD, Commercial, Actual, ราคา หรือ Vendor lump sum จากต้นฉบับมาเป็นผลประเมินใหม่
- MD Matrix ใช้ Activity × L/M/H × จำนวน × ตัวคูณ Stack ของบทบาทที่เกี่ยวข้อง ตามสูตรเดิม
- SAP/Vendor/Migration ไม่มี MD จนลงแรงงานตามบทบาทเอง การเลือก Activity ไว้เพียงอย่างเดียวยังไม่ถือว่าประเมินแล้ว
- **รอประเมิน** ต่างจาก **MD = 0 ที่บันทึกเอง** จึงยังมีคำเตือนในสรุปและป้ายในไฟล์ Export แม้แก้ข้อความแหล่งอ้างอิง แก้รายการรอประเมินก่อนใช้ยอดรวมเพื่อเสนอราคา
- เก็บชื่อไฟล์ ชีต เซลล์รายละเอียด และ SHA256 ในแหล่งอ้างอิงของรายการ ไม่ยืนยัน Baseline ให้โดยอัตโนมัติ ผู้ประเมินยังต้องตรวจขอบเขตและระดับ
- ตาราง Export ใช้ Template มาตรฐานของระบบและชีต Effort Evidence ไม่เขียน MD กลับลงรูปแบบ Excel ต้นฉบับ

## ข้อจำกัดที่แสดงในหน้า

ไฟล์ไม่เกิน 10 MiB, ไม่เกิน 50 ชีต, ชีตตารางงานไม่เกิน 2,000 แถว/80 คอลัมน์ที่มีข้อมูลจริง (รูปแบบเซลล์ว่างที่ลากเกินตารางไม่นับ), เลือกนำเข้าไม่เกิน 1,000 รายการจากหนึ่งชีตต่อโครงการ ข้อมูลสร้างโครงการไม่เกิน 2 MiB และข้อความในเซลล์ไม่เกิน 8,000 ตัวอักษร ถ้าใหญ่กว่านี้ให้คัดลอกเฉพาะตารางที่ต้องใช้หรือแบ่งไฟล์

ชีตซ่อนต้องเลือกเอง ไม่ถูกใช้เป็นค่าเริ่มต้น Phase จาก merged cell ใช้ต่อเนื่องได้ ส่วนรายละเอียดจาก merged cell ใช้เพียงครั้งเดียว สูตรใช้ผลที่ Excel บันทึกไว้ ไม่คำนวณใหม่; ถ้าไม่มีผลจะมีข้อสังเกตให้ตรวจต้นฉบับ ไม่เก็บไฟล์อัปโหลดถาวรและไม่ส่งเนื้อหาไป AI API
